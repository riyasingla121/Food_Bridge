# 🍱 FoodBridge – Community Food Distribution System

## 📌 Project Overview

**FoodBridge** is a web-based Community Food Distribution System designed to help manage and coordinate food distribution activities efficiently.

The system provides a centralized interface to manage **food centers, meal requirements, volunteers, food supplies, distribution schedules, and completion tracking**.

The project was developed as a group project by **ARK Coders**.

---

## 🎯 Project Objective

The main objective of FoodBridge is to make community food distribution more organized and transparent.

It helps users:

- Manage food centers
- Track required and arranged meals
- Manage volunteers
- Monitor available food supplies
- Schedule food distribution
- Track completed distributions
- View important information through a centralized dashboard

---

## ✨ Key Features

### 🔐 Login & Guest Access
- User login interface
- Guest access option
- Logout functionality

### 📊 Dashboard
The dashboard provides an overview of the entire system through summary cards, including:

- Food Centers
- Meals Required
- Meals Arranged
- Volunteers
- Available Supplies
- Meals Distributed

It also displays:

- Distribution completion percentage
- Supply overview

### 🏢 Food Centers
Users can add and manage food center information.

### 🍛 Meal Requirements
The system allows users to record meal requirements and track the number of meals arranged.

### 👥 Volunteer Management
Volunteer information can be added and managed through the volunteer module.

### 📦 Food Supplies
The system allows users to record and monitor available food supplies.

### 📅 Distribution Schedule
Food distribution activities can be organized and scheduled using the distribution schedule module.

### ✅ Completion Tracking
Users can track the progress of food distribution.

The system also performs validation to ensure that the number of distributed meals does not exceed the target number of meals.

### 📱 Responsive Design
The website is designed to work on different screen sizes, including desktop and mobile devices.
